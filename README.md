# newsletters

Personal interest log from newsletters (Product Hunt Frontier, Sunday Roundup, and others).

## Live site

After GitHub Pages is enabled: `https://jgarr16.github.io/newsletters/`

## Layout

- `index.md` — landing page (newest nuggets)
- `log/` — append-only Markdown entries by issue
- `TRAINING.md` — standing interest profile (updated as you check topics)
- Incoming issues are presented as **broad checkbox lists** for training; only checked items are written into the log with excerpt + in-newsletter links.

## Rules

- Self-contained Markdown (no Apple Mail / Gmail deep links required)
- No “why it matched” tags
- Digests stay quiet when there is nothing new
