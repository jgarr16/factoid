INSIGHT

Why the Claude Code team now measures code review in human minutes

Source: The Code, Superhuman

Thirty thousand changes a day. Claude writes roughly 90% of Claude Code's own code, so how does the team review it all? They just shared their exact playbook. Anthropic saw daily changes in its monorepo jump from 2,500 in May to over 30,000 in September. Merged pull requests for Claude Code more than doubled between June and September, and the revert rate dropped by more than 40%.

Reading every line is only a proxy. The real question is what could break and which check will catch it. Here’s what to borrow:

  • Start reviewing before you open a PR. Have Claude run your tests and build, show the results and then pass the diff to a fresh-context subagent.

  • Don’t trust every bug report. Run several reviewer agents, then have a second group vote on which findings are real.

  • Clear every open thread. Before you merge, fix each bug or security finding, or explain why not.

  • Match the review to the risk. Docs can skip human approval once checks pass, regular changes need one reviewer and high-risk code need two. Save the lighter paths for trusted authors.

  • Keep a human accountable. Bot approvals don’t count, and whoever prompted the agent is a required reviewer.

  • Stop going in circles. After three rounds, rethink your approach, then review only the new diff.

  • Count the minutes. Track approvals, comments, and PR wait time. Rising reverts mean you traded quality for speed.

You still need engineers making the big calls. Humans decide what gets built and review billing, CI, the auto-updater, and architecture others will copy. Safeguards that tighten reviews as reverts rise don’t exist yet. And this is Anthropic grading its own tooling.

How to stop auto mode from blocking your own repos

Auto mode is Claude Code’s default, but the classifier doesn’t know your environment yet. It blocks routine actions, like pushing to another repo in your org or hitting an internal domain. Daniel San, Head of AI at Hedgineer, shared the setup that fixes it.

  • Step 1: Update Claude Code.
claude update
  • Step 2: Run the setup command inside a session.
/auto-mode-setup

Claude scans your project, recent sessions, and optionally your shell history, then asks a few questions and drafts trusted repos and domains for your config.

  • Step 3: Confirm the entries took effect.
claude auto-mode config
