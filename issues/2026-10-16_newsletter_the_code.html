GitHub’s infrastructure is closer to breaking but Anthropic has a solution

Source: The Code, Superhuman

Git can’t keep up. When teams hand more coding tasks to AI agents, the bottleneck inevitably shifts to the repository. Anthropic saw its merge volume jump from roughly 2,500 merges per day in May to more than 30,000 in September. Traditional Git simply could not handle that relentless scale. In a recent blog post, the company detailed how a small team of seven engineers built an entirely new replacement in just five months.

GitHub sees it too. While Anthropic's numbers are extreme, GitHub is feeling the exact same pressure. In September, developers and agents generated 7.38 billion commits on GitHub, more than five times the volume from a year earlier. Pushes surged 4.9x, and actions runs more than quadrupled. To handle the load, GitHub is actively rebuilding its Git infrastructure while keeping the site fully operational.

Writes are the hard part. GitHub explains that serving the same code to multiple agents is fairly straightforward because caches handle most of that workload. However, saving their changes creates a much bigger challenge. The system must store each update and make it visible before the next agent can build on top of it. Because agents commit after nearly every step, these merges quickly pile up on the main branch.

Two very different fixes.

  • GitHub is keeping Git and separating storage from compute. Azure Blob Storage holds the data, caching workers handle reads, and only the branch update needs coordination. Internal benchmarks show up to 35x higher write throughput.

  • Anthropic built its own system, Scion. It handles commits, merges, and history lookups on its servers, using 200x less CPU and memory than the old Git mirrors.

The repo is next. Anthropic designed Scion specifically for massive monorepos, so the team is not telling everyone to abandon Git just yet. If your developers run AI agents in tight execution loops, you should closely monitor push latencies and merge queues. Your agents might already be ready for their next assignment while your repository is still struggling to catch up.

AI CODING HACK

How to put Cursor’s agent in rigor mode

Agents ship sloppy work unless you supervise every step. SpaceXAI engineer Lauren Tan shared the 10-second setup for pstack, her skill stack for rigorous autonomous engineering.

  • Step 1: Install it in a Cursor chat:
/add-plugin pstack
  • Step 2: Run setup and choose your budget. It detects the models in your Cursor account and maps them to pstack’s roles.
/setup-pstack
  • Step 3: Start a new chat, then prefix any task you want done rigorously:
/poteto-mode fix the search filter resetting when I change pages

The mode stays active for the session. Run /poteto-help when you're unsure which skill fits.
