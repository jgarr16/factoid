TUTORIAL

How to build an app that cleans messy spreadsheet exports with Claude Opus 5.5

  • Open Claude and select Opus 5.5.

  • Start a new chat and ask Claude to build the tool as an interactive Artifact.

  • Describe the repetitive cleanup job you want to automate and the file format you normally receive, such as CSV exports from a CRM or finance tool.

Sample prompt: “Build an interactive CSV-cleaning app. Let me upload a CSV, preview the data, and clean it with one click. Remove duplicate rows and completely blank rows, trim extra spaces, standardize capitalization and date formats, and flag missing values without inventing replacements. Show a summary of every change made and let me download the cleaned CSV. Keep the interface simple enough for a non-technical user.”

  • Ask Claude to add Upload CSV, Preview, Clean Data, Change Summary, and Download Cleaned CSV controls.

  • Test the Artifact with a real export, with the kinds of errors you normally encounter.

  • Check the cleaned output and tell Claude about any edge cases it handled incorrectly.

  • Save the Artifact and reuse it whenever you receive a new export. You can also share the tool with colleagues via Claude’s Artifact sharing controls.
