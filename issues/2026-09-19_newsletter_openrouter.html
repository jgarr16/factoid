You are not charged when a model returns nothing

Billing

You are not charged when a model returns nothing.

When a request comes back with no output tokens and either a blank finish reason or an error, OpenRouter does not deduct credits for the model's prompt, completion, or reasoning tokens. This holds even in cases where the upstream provider charged us for prompt processing.

Read the details

What zero completion insurance covers

01

On by default, everywhere

It applies to all requests across all models and providers, on every account, and there is nothing to configure.

02

Visible on your activity page

Requests that were protected show zero credits deducted for token usage.

Zero completion insurance →

03

One boundary worth knowing

Auxiliary work that already ran before the response failed can still be billed for what it actually did. Web search fees, file parsing, and web fetch fall in that category, and when they are billed they appear in the request's usage breakdown.

This is worth checking your retry logic against.

Code written to treat a failed generation as sunk cost is guarding you against a charge that is not there.
