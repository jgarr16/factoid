Server tools

Three new tools that keep expensive models off the work a cheaper one can do.

01

Fusion

When one model would miss a hard question, fuse a panel instead. Send one prompt to openrouter/fusion, a panel answers in parallel with web search, and a judge synthesizes one grounded answer. Frontier-grade research without frontier rates on every call.

Read the benchmark →

02

Advisor

Run a fast, cheap model as your executor and let it consult a stronger one only when it gets stuck, instead of paying premium rates on every token. You pick which model executes and which one advises.

Advisor docs →

03

Subagent

Keep your expensive model off the grunt work. A large model breaks a task into self-contained subtasks and hands them to a smaller, faster worker model mid-generation, then assembles the result.

Subagent docs →
