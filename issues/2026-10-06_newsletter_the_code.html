How engineers at Warp run software factories

Source: The Code, Superhuman

The hard part. There's been plenty of talk lately about agents writing code and where human review fits in. Now Warp, the agentic development platform, is offering a look inside their workflow. Developer Ben Holmes has shared how the company's own code moves from a Slack request to production, with agents checking each other's work along the way.

Agents review agents before a human looks. Every request follows the same path, and agents handle most of it:

  • Intake: The team drops a request into a Slack thread or a Linear issue.

  • Triage: An agent digs into it and decides whether to send it to the builder, ask for more details, or park it for later.

  • Spec: If the request needs fleshing out, a subagent draws up a plan for a human to approve.

  • Build: With the direction settled, the implementation agent writes the code.

  • Verify: Another subagent runs the change end to end to check that it actually works.

  • Review: A code review agent and the builder go back and forth on fixes before a human takes a final look and ships it.

  • Monitor: Once the code is live, an automation watches for alerts and opens a new ticket if something breaks.

Production feeds the queue. That last step is what starts the whole thing again. A bug turns up in production, becomes a ticket, and gives the agents their next job. Holmes calls monitoring the first step toward closing the factory loop. Humans still decide what gets built and what ships.

It's already paying off. Warp was able to cut its internal cost per PR from $80 to $30. If you are ready to build your software factory, you should check out Warp's starter templates or request early access to their Factories.

How to let Claude Code configure itself

A dev shared an Anthropic plugin most others miss. Claude Code supports hooks, skills, MCP servers, and subagents, but nobody knows which ones their project actually needs. The claude-code-setup plugin scans your codebase and tells you.

  • Step 1: Open Claude Code inside your project folder so the plugin can see the code. You need version 2.x for plugin support.
claude
  • Step 2: Install the plugin from Anthropic's official marketplace, which loads automatically:
/plugin install claude-code-setup@claude-plugins-official
  • Step 3: Ask it to analyze the project. It recommends hooks, skills, MCP servers, and subagents, then walks through configuring each one. It's read-only, so nothing in your repo gets touched.
