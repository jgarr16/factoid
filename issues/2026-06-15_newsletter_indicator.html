Get your machine set up for OSINT

I recently bought a new laptop and it prompted me to consider the tools I use and how I’d set up my machine. I decided to use it as an opportunity for a bit of spring cleaning, and to ask people how they get set up for OSINT. I put out a public call to the community to share their suggestions, and reached out to some investigators I know.

Not surprisingly, there are a variety of approaches to setting a machine up for investigations. Some investigators wipe everything from their machine and install a minimum number of applications, aside from essentials like a virtual machine and VPN. They prefer to access tools as needed from a dedicated browser. Others run most of their tools from the command line.

There isn't one perfect setup. As such, this guide doesn’t cover every use case, and there are other options that might work better for some people. It’s also geared towards investigators who don’t write or run their own code or tools. Maybe it confirms that you already know most of the popular tools. Or it helps you set up or tweak your setup.

For each category, I suggest free tools and highlight open-source options. There are often multiple options for the same thing in a category, so it comes down to personal preference. But in some cases you may want to install multiple tools that perform the same function, as some may return unique results. I also cite a few paid options when relevant. (None of them are paid placements.)

This guide strictly focuses on local installations and browser extensions. Web-based tools that don't require local setup were excluded. Think of this as a starter pack for an OSINT machine/browser. If you’re looking for specific tools, you can always run a search in OSINT Navigator, our free app to help you find the right tool for the job.

A final, important note: tools don’t make you an investigator or OSINTer. One of the questions I asked people was if there are tools they can’t live without. I got a great response from Justin Seitz, the cofounder of Hunchly and Permanent Record Research:

““None really, I truly could have all of the aforementioned tools vanish tomorrow and I would not feel lost moving to a parallel tool or reverting back to a more primitive form of research.”“ —

Another person, who asked to remain nameless, said the one tool they can’t live without was “A physical library card.”

OPSEC

Tools to help you stay safe and private

There are certain non-negotiables, and a good VPN is at the top of the list for digital investigative work. It ensures a basic level of privacy while browsing the web. A password manager is also of course essential for everyday life, let alone OSINT work.

Aside from those, many people use a virtual machine to segment their investigative work from the rest of their machine. Others use a dedicated machine for investigations.

“The first thing I honestly do when I get a new device is uninstall everything that they come preloaded with,” said Nicole Hurey, founder of The OSINT Vault and Paradox Index. “I personally like to start off with a clean and controlled environment before I add anything.”

Derek Bowler, who led Eurovision’s verification unit and is working on a new OSINT project, said you need “A disciplined operational layer before you open a single tool.”

He added:

“That means a dedicated browser profile (or hardened browser like Mullvad Browser or Firefox with uBlock Origin and Canvas Blocker) running through a reputable VPN for any collection session. I use Mullvad and Proton VPN depending on context. A virtual machine, ideally via VirtualBox or VMware, for anything touching hostile infrastructure or high-risk subjects. Separate burner accounts for each platform you monitor — never linked to your real identity, built on throwaway email addresses (SimpleLogin or similar), and accessed only through your VM/VPN stack. A password manager (Proton Pass is free and integrates cleanly with the rest of the Proton stack).”“ —

Virtual Machine

If you don’t use a dedicated machine for investigations, virtual machine software can help segment and protect your investigative work.

  • VirtualBox: free, open-source virtual machine.

  • VMware: free virtual machine.

  • Trace Labs OSINT VM: a pre-built VM image for OSINT that you can import into VirtualBox or VMware. One nice element is that it comes with Obsidian pre-installed and you can load a tools script that installs a set of open-source OSINT tools, many of which are suggested below (Sherlock, SpiderFoot, exiftool). It also comes with a “hardened” version of Firefox for browsing, as well as Tor.

  • OOSU10: a free Windows-only tool recommended by Joshua Richards from OSINT Praxis. He uses it “to remove telematics from Windows and generally improve OPSEC.”

Ad blocker

  • Adblock Plus: free blocker that works on a variety of browsers.

  • Ghostery: the free version offers a solid ad blocker. It also gives a nice visual report of the trackers on a given page.

  • uBlock Origin: another solid option, though the full version doesn't work in Chrome. For that, use uBlock Origin Lite.

Burner account

Many people said they have burner accounts on different social platforms. In many cases, they use a dedicated phone number, SIM card, and email address to create them.

“I've created dedicated research accounts on platforms with strong recommendation algorithms,” said Benjamin Strick, who writes the OSINT Field Notes newsletter, publishes videos on YouTube, and leads investigations for the Centre of Information Resilience. “I do this partly for privacy and research purposes, but also for my own wellbeing. I don’t want war crimes footage appearing on my personal Instagram feed on a Sunday morning … I'd suggest to anyone else who is going to focus on a specific geography or subject matter, to think about how they're going to approach social media platforms, over and above keyword searches.”

Joshua Richards from OSINT Praxis also suggested 10 Minute Mail, which he uses to create “temporary email for accounts I might only access one time.”

Paid upgrades: Kasm Workspaces, Silo Workspace, Parallels Desktop, SockPuppet.

Setup

Tools that help you run/install other tools, and provide access to the web.

Core apps/installs

  • Obsidian: I was an Evernote user for well over a decade. I regret not switching to Obsidian earlier. It’s free and a perfect fit for OSINT. Privacy, graph visualization, entity creation and linking, integration with outside tools and LLMs (if you like), and the ability to pay $5 a month to sync a vault across devices.

  • Notepad++: another free notetaking option. “Much better features than basic Notepad, helps to speed up basic workflows for quick notes, maybe before choosing to dedicate everything into an Obsidian vault,” Richards said.

  • Python:** **many of the best open-source OSINT tools are written in Python. That used to be a barrier for some. But now LLMs have made it so easy for non-technical people to install and run programs in this language. I suggest several in the sections below. Note that some Python tools are available in web-based versions, but they may not be as powerful.

  • Docker:** **a way to run open-source tools in a containerized environment — an option for people who prefer not to run tools through Python in the terminal.

  • Maltego CE: the community version enables you to easily create network graphs. It was recommended by several people. (There are also free web-based visualization options like OSINT Tracker.)

Browser

This is a personal choice. Some people understandably avoid using Chrome due to its data collection practices. The tradeoff is that it has the most appealing extensions. Chrome can also run skills, which I detailed here. One approach is to segment your activity across different browsers and to use a privacy-enhanced app whenever possible.

  • Brave: privacy-enhanced browser that also has a built-in VPN. (However, running a dedicated, independent VPN is still highly recommended.)

  • Chrome: included because of the many extensions it supports, the Gemini integration, and skills.

  • Firefox: offers lots of plugins/extensions, including one that allows you to segment cookies/identity. Preferred by some to Google due to privacy concerns.

  • Edge: built by Microsoft.

  • Mullvad Browser: a privacy-enhanced browser built by the makers of the popular VPN.

  • Orion: recommended by Hurey, who said it’s her primary browser. Built by the people behind the paid Kagi search engine, it positions itself as offering “absolute privacy.” It also can run some Chrome/Firefox extensions. Review the list of guaranteed-to-work extensions here. It only works for macOS for now, but Linux and Windows are in development.

  • Tor: great for browsing the dark web.

Web Capture/Archiving

I published a detailed look at web capture tools. Some of the features have evolved since then, but it’s still the best read if you want a detailed look at apps and extensions.

Extensions

  • Ubikron: a full-featured, free continuous capture tool. Content is saved on their servers, or you can pay and get your own private server.

  • Forensic OSINT: offers a limited free version.

  • GoFullPage: useful for capturing long webpages thanks to its auto-scroll ability.

  • Wayback Machine: the OG web archiving tool. Its extension has a lot of great features. You can read my guide to it here. Available in many browsers.

Video downloading

  • yt-dlp: open-source Python tool that can download the video from social platforms and online sites. Mentioned by several people I spoke to. Web version available here.

  • Stacher 7: a nice desktop app built on top of yt-dlp. Easier to use.

  • JDownloader2: free tool mentioned by one reporter who uses it “to scrape some hard-to-get videos.”

Paid upgrades: Hunchly, Forensic OSINT, Ubikron, SnagIt.

Identity/Account Analysis

There are tons of tools and techniques for investigating people, entities, accounts etc. Many of the best are available on the web, so the below list is by no means comprehensive. But these are some you can consider installing.

Software

  • Blackbird: enumeration tool that checks if a username is present across many online services.

  • GHunt: extract data about a Google account, including profile photo and public reviews.

  • Holehe: enter an email and see if it’s connected to an account across more than 120 online services, including social media sites.

  • Maigret: username enumeration tool that checks for matches across thousands of services.

  • Sherlock: username enumeration tool.

  • Social Analyzer: “PI, CLI, and Web App for analyzing & finding a person's profile across +1000 social media \ websites.” (Thanks to OSINT analyst Jan Kock for suggesting this.)

  • SpiderFoot: multipurpose free and popular OSINT tool that can search by username, email, phone number, name, Bitcoin address, etc.

Extensions

  • SignalHire: offers free credits that can help extract emails and phone numbers from LinkedIn profiles.

  • Lusha: same.

Paid upgrades: Epieos, OSINT Industries, SkopeNow, Usersearch, .

Visuals

Tools for analyzing images and/or video, including metadata and satellite/spatial imagery. As noted in other categories, this does not include web-based tools and products, of which there are many.

Software

  • ExifTool: free application that can read metadata from a wide variety of files.

  • Gephi: open-source graphing software. Great for network maps.

  • Google Earth Pro: free desktop app that provides access to historical satellite imagery, and more. (It also has a web version if you prefer not to download it.)

  • QGIS: free spatial visualization tool that Bowler said is essential “for any mapping or geolocation-heavy investigation.” Also cited by Strick and Perez de Acha.

  • VLC Media Player: cross-platform media player that’s useful for frame-by-frame breakdowns of videos.

Extensions

  • Image Witness: Bowler built this extension. As with InVID and Search by Image (listed below), it enables you to search an image across multiple reverse search engines. One added benefit is that it hashes each image for proof/preservation: “Every action is captured in a local activity log: timestamp, session ID, image URL, image-URL hash, source URL, service used, target URL.”

  • InVID: the Swiss Army knife of image/video extensions. It offers an array of image and video tools for reverse image search, thumbnail extraction, YouTube video analysis, metadata analysis, and more.

  • Search by Image: a simple, free reverse image tool that quickly connects you to the major search engines. It also has a ton of customization options.

Paid upgrades: Planet Labs, Vantor, and other satellite imagery providers.

Websites

Many excellent tools for investigating websites are web-based, so this is a list of useful open-source tools and browser extensions.

Software

  • Photon: useful free tool for crawling a website.

  • Recon-ng: feature-rich web reconnaissance tool. Subdomain enumeration, certificate analysis, and much more. It also integrates with APIs from services like Shodan, etc.

  • SpiderFoot: as previously noted, can search by domain, as well as IP address, ASN etc.

  • theHarvester: popular free tool that “gathers names, emails, IPs, subdomains, and URLs” from a website. You can also add a wide range of API keys.

Extensions

  • SimilarWeb: one of the best tools for analyzing web traffic. The Chrome extension gives three months of data for free, as opposed to one month in the web version.

  • BuiltWith: get a snapshot of the technology used by the webpage you’re on. Worth it for the "Relationship" tab data alone.

  • Wappalyzer: similar to BuiltWith, but offers a much easier to read quick snapshot of tech on the page.

  • HTML Inspector: I outline more detail about this tool here. It’s a really easy way to check a webpage for interesting file names, Javascript or HTML comments, and more.

  • BrandSearch: read more on it here. Essential if you’re looking into an ecommerce site.

  • Wayback Machine: mentioned above, but including it again.

Paid upgrades: As noted above, there are tons of great passive DNS and web recon tools; too many to mention here.

Bookmarklets

I’m making an exception to my no-bookmarks rule for this guide in order to include the free bookmarklets offered by My OSINT Training. I previously wrote a post about their value and why you should use them.
