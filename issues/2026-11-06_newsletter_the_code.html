Why devs should be building more ‘ambitious’ software

Source: The Code, Superhuman

50x faster. So what? Imagine making Rust builds 50 times faster and deciding it’s not worth a blog post. Well, that’s exactly what senior engineer Dan Luu did. While devs complained about slow Rust compiles, he had an AI agent build an interpreter that made cold builds roughly 50x faster, by his informal estimate. Five years ago, that would have been a big deal. Today, Luu didn’t think it deserved a writeup. That says a lot about how devs approach AI.

The old math is broken. In a new essay, Luu argues that devs should be building bigger, more ambitious software now that agents are around. But most still size projects by how much work they used to take. Luu also built a regex engine and a ripgrep fork with no experience in either. Work he’d once have set aside a year for took a few hours.

Chase the slow bits. Luu’s tips for picking what to build:

  • First, find out where your computer spends its time when models run ten to one hundred times faster.

  • Then tackle those bottlenecks. For Luu, that meant ripgrep, Rust compiles, and filesystem overhead.

  • Build for yourself. If it works for your own workloads, that’s enough.

  • Think bigger. Speeding up old tasks with AI only gets you so far. Go after work that used to be too expensive.

  • Don’t get attached to your tools. Models improve so fast they could be obsolete in three months.

Slop needs a safety net. Luu admits most AI rewrites are slop, so testing is everything. He relies on fuzzing and property-based tests rather than traditional unit tests. And your own coding skills still matter. With every new model, Luu tackles harder problems where AI still struggles. He argues that programming skills are more valuable than ever. AI CODING HACK

How to burn leftover Codex quota before it resets

A dev shared a fix for quota that resets half-unused: point Codex’s /goal command at the cruft months of vibe coding left behind.

  • Step 1: If /goal doesn’t appear in your slash menu, enable it:
[features]
goals = true
  • Step 2: Set a cleanup goal. Codex keeps working across turns until it’s done:
/goal Remove all dead code nothing calls, verified by passing tests

The full thread has four more targets: duplicated logic, unused dependencies, stale sessions, and zombie scheduled tasks.
