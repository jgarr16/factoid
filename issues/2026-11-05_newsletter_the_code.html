INSIGHT

Anthropic engineer warns coding agents erode your critical thinking. Here's how to fix it:

Source: The Code, Superhuman

Addy Osmani, who works on Claude Code at Anthropic, just sounded the alarm for software engineers: smarter AI agents are quietly dulling our critical thinking skills.

Because newer models generate clean, working code with fewer obvious bugs, engineers rarely pause to double-check the logic. We used to spend time reasoning through complex problems between asking a question and building a solution. Agents now eliminate that window, removing the friction that forces us to think.

Osmani maps this shift across three distinct stages:

  • Cognitive offloading: You delegate a specific task to an agent while maintaining full ownership of the final output.

  • Deferral: You accept the model's output as truth rather than treating it as an unverified hypothesis.

  • Cognitive surrender: You adopt the code entirely as your own without reviewing it, assuming manual checks waste time.

This drift creates compounding comprehension debt: your repo fills with passing tests, but no engineer on the team truly understands how the architecture works.

To break this cycle, Osmani recommends a few practical habits before and after running agents:

  • Form a hypothesis first: Draft your own rough solution so a polished AI answer does not anchor your thinking.

  • Define verification upfront: Decide your success criteria before running the prompt so you do not rationalize buggy results later.

  • Hunt for failure modes: Ask what assumptions could break the code, then run real edge-case tests.

  • Inspect the raw evidence: Review the exact commands and outputs before reading the model's summary.

  • Challenge green checks: Ask which edge cases passing tests actually missed.

  • Demand explicit trade-offs: Prompt the agent to list the decisions and shortcuts it took.

The conclusion is simple: if you cannot explain the architecture, even with the agent's help, you have surrendered your judgment.

AI CODING HACK

How to stop Claude Code’s subagents from eating your usage limit

Background subagents in Claude Code were wasting your usage limit because every 30 seconds each one reread its entire conversation just to update a short status line.

Anthropic’s Claude Code team fixed the issue. A smaller model now writes the status line using short notes. That makes each update about 99% cheaper, giving you roughly 6% more prompts within your limit.

  • Step 1: Check your version.
claude --version
  • Step 2: If it’s below v2.1.316, update.
claude update
  • Step 3: If you installed Claude Code with npm, run this instead of Step 2.
npm update -g @anthropic-ai/claude-code

That is all there is to it. Just restart any active sessions to apply the update, and keep in mind this only applies to the CLI.
