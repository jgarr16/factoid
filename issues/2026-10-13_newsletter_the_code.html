How to keep learning in the age of LLMs

Source: The Code, Superhuman

Faster code, less learning. AI coding tools have made developers faster, but many are learning less. When an LLM solves almost any problem on the first try, developers skip the friction that actually builds skill: making mistakes, figuring out why, and remembering how to fix them. Software engineer Oğuzhan Olguncu noticed this in his own work. He stopped working through hard problems because the effort felt pointless, and his growth stalled.

Turning the LLM into a mentor. To break through that plateau, Olguncu changed how he used the LLM. He rebuilt a small database from a research paper, writing the core logic himself. Whenever he got stuck, the model acted like a mentor, prompting him with questions that pointed toward the bug so he could solve it on his own.

His rules for learning with AI. That project shaped the rules he now follows:

  • Use the LLM as a mentor that asks questions, and write the important code by hand.

  • Give the LLM the routine work, such as tests and tooling.

  • Plan each project with the LLM before starting, so progress depends less on willpower.

  • Make progress visible with a simple chart or tool.

  • Work in short, regular sessions. Thirty minutes a day beats two hard days followed by ten days off.

  • Pick topics slightly beyond current skill, and ask the LLM to explain again as often as needed.

The same rules work for teams. An engineering team can move fast with AI while still protecting the deep thinking that turns junior developers into senior engineers. Olguncu shared his skill on GitHub and encourages others to adapt it to their own learning styles.

AI CODING HACK

How to find what’s filling up Claude Code’s context

Claude Code's context window fills up fast and running “/context” gives you just a snapshot. That makes it tough to tell which turn burned through your tokens. To fix this, an engineer built a mod that breaks down each request into inputs and outputs.

  • Step 1: Mods need Claude Code v2.1.287 or later.
claude --version
  • Step 2: Install the mod from your project folder using the terminal.
npx claude-code-templates@latest --mod ui/turn-inspector

If a session is already open, run /reload-plugins to load it.

  • Step 3: Open the inspector.
/turns

Each request appears as a row with a bar that indicates how much of the window it occupies. Expand a row to view its input and output sections block by block, from the system prompt to each tool result, making it easy to identify the call that filled your context.
