GPT-4o and GPT-4.1 models retire January 14, 2027

OpenAI’s GPT-4o, GPT-4o mini, GPT-4.1 and GPT-4.1 mini retire on January 14, 2027. After that date these models will no longer be available through OpenRouter. This includes requests that use your own OpenAI API key (BYOK).

Requests to these models will fail after January 14, 2027, so switch to another model before then to avoid an interruption. The retiring model IDs are:

openai/gpt-4o openai/gpt-4o-2024-05-13 openai/gpt-4o-2024-08-06 openai/gpt-4o-2024-11-20 openai/gpt-4o-mini openai/gpt-4o-mini-2024-07-18 openai/gpt-4.1 openai/gpt-4.1-mini

To switch, change the model ID in your requests. This applies to BYOK requests too. Two OpenAI models you can switch to:

OpenAI GPT-6 Luna OpenAI GPT-5.6 Luna
