How to build a simple, playable mobile game with Claude Opus 5.5

Photo: Gaming the Past

  • Open Claude on web, select Opus 5.5, and make sure Code execution and file creation are enabled under Settings > Capabilities.

  • Start a new chat and describe a very simple game concept, such as tap-to-jump, dodge falling objects, memory match, endless runner, or reaction timer.

Sample Prompt: “Build a mobile-friendly browser game called [name]. The player should [core mechanic]. Use large touch controls, responsive portrait layout, a score counter, restart button, increasing difficulty, simple animations, and clear win/lose states. Make it playable entirely inside a Claude Artifact with no external setup. Keep the code lightweight and optimized for phone screens.”

  • Ask Claude to create the result as an interactive Artifact rather than only returning code.

  • Open the Artifact and test the full loop yourself: start → play → score → lose/win → restart, checking every button and touch interaction.

  • Switch to your phone and open the same Artifact in the Claude app to test tap targets, layout, text size, and performance.

  • Return to the chat with specific fixes. Add one polish pass for sound toggle, high score, start screen, difficulty curve, and simple visual effects, then retest on mobile.

  • When it works, click Share and create a link so other people can open and play the Artifact.

FROM THE FRONTIER

Agent-flation is a serious possibility, but only if websites gives them access.

Made with Midjourney

Just last year, the thought of handing your credit card to AI sounded absurd. Today, it’s quickly becoming the norm, and that shift could make everything you buy more expensive.

💳️ The Wallet Wars. Tech giants have rushed to make agent payments a reality. Visa and Mastercard introduced agent payments in April, with PayPal, Stripe, Cloudflare, and Coinbase following shortly after. Agent payments promise more convenience to shoppers, but they could also disrupt a delicate ecosystem.

Why agent-flation might be on the way

  • Retail ads are big business. Amazon reported a whopping $68B in ad revenue in 2025, with Walmart also bringing in $6B. That income helps subsidize lower prices, along with perks like free delivery and streaming. They’re not alone: Uber, Instacart, and Etsy all run sizable ad businesses.

  • Agents don’t click ads. Every time an agent makes a purchase, it means a real human didn't visit a website and click a sponsored post. If this trend eats into ad revenue, companies could make up the difference by raising prices, fees, or subscription costs.

But walls are going up. Many platforms are already taking protective measures. Amazon blocked Meta’s Muse agent in September. Now Yelp, eBay, Zillow, Pizza Hut, Adidas, and several airlines have followed suit. Companies are jockeying for control of how you shop, and whoever wins could influence how much you pay.
