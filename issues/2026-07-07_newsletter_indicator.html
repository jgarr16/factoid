No code, no budget: 7 web scrapers put to the test

For me, web scraping has always carried an illicit thrill. It's a combination of a jewel heist, jigsaw puzzle, and lockpicking.

I began web-scraping 13 years ago, when I was starting out as a data journalist. I understood scraping but had never coded a functioning scraper; learning Python was daunting.

In 2013, Duke University's Reporters' Lab asked if I could test and review enterprise scraping software. I jumped at the chance to learn how to crawl, parse and extract unstructured data from websites. It enabled me to land scoops that helped me gain a foothold in the industry. At the time, you needed at least basic coding skills to be able to use the tools I reviewed. And as much as I loved web scraping, it was a pain in the ass, even with coding skills and premium tools.

That’s no longer the case. Today, you can scrape webpages, including those with features like dropdown menus and infinite scroll, or protections like Cloudflare, without technical expertise or a big budget. There are browser extensions, AI-assisted tools, and other options that put scraping in the hands of any investigator. To help you decide which scraper is the right fit for your needs, I put seven options to the test.

Methodology

Tool Selection

Indicator selected seven web scraping applications/packages that offer some form of free access. Most of the scrapers have additional premium features, which I did not use. I wanted to see how far I could get with the free tier. When tools allowed for different ways to run them — such as a desktop app or a command-line interface — I’ve noted which implementation was used in my testing.

Types of Scrapers

The scrapers tested generally fell into three categories, though there was a certain amount of feature overlap:

  • Platforms: These scrapers often include a graphical user interface to select website elements and build scrapers. They typically offer numerous other features, including AI integration, ready-made templates, and the ability to monitor specific webpages.

  • Browser Extensions: These scrapers were installed via the Chrome Web Store (I used the Brave Browser). They are typically no-code, incorporating point-and-click and conversational-AI element selectors.

  • Repos: These scrapers had GitHub repos that could be installed and run via command line or a Python IDE.

Test Websites and Scoring System

I chose websites for testing that permitted automated data extraction. This meant I did not scrape any of the major social media platforms, which explicitly prohibit scraping in their robots.txt. (Some tools, such as Apify, say they can scrape social sites.) The three websites/tasks were:

  1. Wikipedia - List of Legendary Creatures (Novice)

Why it was chosen:

I like mythical creatures, okay? Plus it allowed me to see if scrapers could:

  • Navigate to the List of legendary creatures webpage and collect all of the alphabetically listed URLs

  • Take the list of URLs, navigate to each legendary creature subpage and extract information from the page

The challenge:

  • Each legendary creature entry isn't in a clean, structured format. The pages contain a mix of URLs and free-floating in-line HTML without dedicated fields or CSS classes to target.

Deliverable(s):

  • Extract data on all 1605 Legendary Creatures

Test 2: SEC EDGAR Text Search for all documents responsive to "Elon Musk" (Moderate)

Why it was chosen:

To see how scrapers handle a website with clickable elements. In this case, the EDGAR Text Search has clickable toggles for displaying additional columns. It’s further complicated by the fact that two of the columns are pre-selected.

The challenge:

  • EDGAR Text Search doesn’t allow you to navigate past page 10 via browser navigation. Batch scraping is required to retrieve every result.

Deliverable(s):

  • Batch scrape responsive records with all columns selected

Test 3: DocumentCloud Search for all publicly available documents that include "Justin Trudeau" (Hard)

Why it was chosen:

DocumentCloud is built with Svelte, a JavaScript framework that poses numerous scraping challenges. Also, I'm Canadian.

The challenge:

  • DocumentCloud uses an "infinite scroll" to load more records. Each infinite scroll triggers an async API call for the next batch of results, which is complicated by inconsistent timing in terms of how the DOM renders each new batch of results. This is what pain is.

Deliverable(s):

  • Capture the document title and document URL

  • Navigate to individual documents using the document URLs and extract the "Last Updated On" text field

  • Successfully trigger DocumentCloud's infinite scroll to load additional batches of documents and repeat data extraction

Scoring System

The amount of tooling required to capture 100% of the desired data can become an exercise in diminishing returns. In some cases, the juice ain't worth the squeeze. I came up with three scores (success, partial success, and fail) to judge the effectiveness of each task:

Test Result

Explanation

Success

The scraper either achieved or was extremely close to hitting the deliverable, with minor manual input or revisions needed

Partial Success

The scraper fell short of satisfying the deliverable, but additional troubleshooting could reasonably be expected to improve results.

Fail

The scraper failed to achieve the deliverable.

Use of AI

A paid Claude Pro AI subscription was used to analyze test websites and troubleshoot most, if not all, of the scrapers tested, to varying degrees.

Findings

I'm blown away by the progress scrapers have made over the past decade, particularly the Chrome extensions and AI tools.

The ability to use conversational language to craft complex scrapers truly lowers the skill floor for the average investigator. Back in 2013, the tools that I tested involved painstaking trial and error, and required you to have a decent grasp of HTML and CSS; I still think investigators will fare better with this knowledge, but it’s no longer a prerequisite. Those same tools also cost hundreds of dollars per license and required a standalone program. Current premium scraping platforms like Webscraper.io offer tools with similar functionality for free, as is the case with their browser extension. Yesterday’s premium scraper is today’s loss leader.

However, unless you have a background in computer engineering, you are going to have to spend money somewhere to ensure you are able to scrape websites with any sense of consistency. Many of the tools require you to spend credits to unlock advanced functions, such as batch-scraping URLs, or maintaining multiple projects at once.

The tools that don't gatekeep such functions require you to know your way around object-oriented programming languages such as Python. They provide an excellent scraping framework, but you're more or less left to your own devices. While my Python skills have increased since 2013, I'm still very much a novice. I found myself using Claude frequently.

Being able to "say" what you want to scrape feels almost too easy — but it'll cost you.

Apify

Apify bills itself as "the largest marketplace of trusted tools for AI." But even if you eschew AI integration completely, its online marketplace offers a plethora of web scrapers that can be run in-browser using Apify's GUI. The free tier gives you $5 of free credits, which actually stretches incredibly far depending on the scraper you select. Some scrapers are free, or charge per result (such as this Instagram Scraper which charges $1.50 per 1,000 results), which is great for tinkering.

Browse AI

Browse AI is a scraping platform offering everything from web scraping and website monitoring to full managed services.

Its approach to AI scraping is unique among the tools I tested: to build a web scraper, you train individual AI "robots" that you can chain together into a scraping workflow.

The robots "watch" you navigate your preferred workflow in your browser during a toggled "Recording" session.

Verdict

Browse AI's AI Scraper is a capable no-code solution for easy-to-moderate scraping tasks, provided you have the credits.

Firecrawl

Firecrawl is hard to categorize. It's a web-scraping platform with full AI integration, as well as an "Interact Playground" that allows you to scrape and extract data using AI prompts (similar to Thunderbit). It can also be initialized using Python from the command line. And there’s an open-source version.

You need an API key to use the cloud scraping services, which consumes credits. You get 1,000 credits with the free tier. However, if you have the technical know-how and resources, the platform is fully open-sourced under an AGPL license, allowing you to self-host it for free.

For my testing, I used the free cloud service from both the command line and Interact Playground just for fun.

Verdict Much like Crawlee, Firecrawl was able to handle nearly everything I threw at it. Unless you're willing/able to set it up on your own server, you’ll eventually need to purchase credits.

Octoparse (desktop app)

Octoparse is a "no code" platform that utilizes "AI-powered autodetect" and a point-and-click interface to build web scrapers. It's one of the two tools I tested that offers a library of ready-made templates for scraping, as well as robust AI and agent integration. For the test, I used Octoparse's desktop app to create custom scrapers.

Octoparse loads a target website with its native browser. Users have the option of using AI auto-detection as well as user-guided element selection to create a custom scraper. A data preview at the bottom of the screen helps optimize the scraper before deployment. Upon execution, Octoparse loads the page and begins scraping.

The Octoparse Dashboard

Verdict

Octoparse's desktop app is a great entry point for OSINT investigators with little to no scraping experience. Its free tier offers plenty of options for experimentation. However, the in-browser rendering can pose a challenge for more difficult webpages.

Browser Extensions

Thunderbit

Thunderbit is another web-scraping platform with its own browser extension, similar to Webscraper.io. What sets it apart is the ability to select elements from a web page by writing an AI prompt. The browser extension offers a limited free tier.

It offers all the standard WYSIWYG web-scraping functionality, but the real star of the show is the Field AI Prompt feature, which allows you to tell Thunderbit what you'd like to scrape in plain language.

Verdict

I was genuinely impressed by its AI functionality. I wish I had more time to put it through its paces.

Webscraper.io

Although Webscraper.io's core service is automated cloud scraping, it offers a free browser extension for local use.

Opening the extension from your browser gives you functionality similar to some of the other scrapers I tested, including auto-detection of data elements, pagination and scroll selections, and export options.

However, the real magic happens when you turn on Advanced Scraping via DevTools:

This allows you to fine-tune a scraper based on a page/site’s sitemap. You can select specific elements and direct scrapers across parent and child URLs for multi-level scrapes. It's a surprisingly robust tool for the price, though it does have some limitations.

Verdict

Though you'll have to make some compromises, Webscraper.io is easy to recommend for the price. I also love that it's just sitting in my DevTools, ready to go when needed.
