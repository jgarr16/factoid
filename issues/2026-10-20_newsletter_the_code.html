Cloudflare’s new model reads messy data faster than normal LLMs: The web infrastructure giant just previewed Clairic, an extraction model that skips text generation. Where its sibling Clef picks a decision from options you define, Clairic pulls typed values straight from the input in one forward pass and returns null when the value isn’t there. When you run both models before an LLM, the LLM receives clean data directly and never has to parse the messy original input. Cloudflare says this setup was 3.2x faster and 49% cheaper than using an LLM alone.

Your coding agent just got a creative studio: Two releases are giving agents more to do. The Sunra MCP server puts leading image, video and audio models inside Claude Code, Cursor, and Codex with one npm install. You can generate app assets, demo videos, and voice-overs without leaving your agent. Meanwhile, Replika’s founder just launched Wabi 2.0. It is a multiplayer personal agent that builds mini-apps inside your group chats.

Inception bets on diffusion to speed up agents: The AI startup just dropped Mercury 3, a new LLM that drafts answers in parallel at 1,068 tokens per second. That means less waiting on your agents, plus a 1M-token context window to work with. Inception claims it beats GPT-6 Luna and Claude Haiku 5.5 on agentic coding, though Haiku still wins on longer coding tasks. It’s live on OpenRouter, Vercel, and Baseten, with launch prices starting at $0.10 per million input tokens.

INSIGHT

Your cheap AI model just needs a harness. Here’s why:

Source: The Code, Superhuman

Cheap, but unreliable. Smaller AI models are tempting for coding tasks because they cost less, and teams rarely choose a model on raw intelligence alone. But they often struggle with consistency. Specmatic founder Naresh Jain wanted to know if a behavioral harness (a set of specs, examples, and tests that flag mistakes as an agent codes) could close that gap.

40 builds. To test this, he decided to run an experiment. He had Codex build the same Java backend with OpenAI’s flagship GPT-6 Sol and cheaper GPT-6 Luna. Each model got 10 attempts on its own and 10 more backed by the Specmatic harness. Then each build faced 178 hidden acceptance tests.

Luna needed a lift. Left to itself, Luna passed just 3 of 10. With the harness, it passed all 10, matching Sol’s perfect record for $0.273 per run, about 33% less than unaided Sol’s $0.406. Giving Sol the same help changed nothing except its bill, which jumped about 7x. The extra guidance paid off only for the model that needed it.

Check smarter. Jain’s takeaway is that you should tailor your testing strategy to your model’s capabilities. Every model needs an independent check, but some need more guidance along the way. Here’s his advice:

  • Cheaper models. When results are inconsistent, keep the harness running as your agent codes. Failing tests act as “executable attention,” catching mistakes before it builds on them.

  • Frontier models. Run the same tests once as a final gate, keeping overhead low.

  • Specs and examples. Your tests only cover what you put into them, so keep them current and let human review catch the gaps.

Starting Point. Jain shared the full application brief, so you can rerun the comparison with your own models and decide what works for you.

AI CODING HACK

How to QA your launch with 5 synthetic users

Your first users hit bugs you never saw, then leave without telling you why. A dev shared a Claude Code prompt that spins up five subagents acting as your worst first-time users before launch.

  • Step 1: The subagents need a real browser, so install the Playwright MCP server first:
claude mcp add playwright -- npx @playwright/mcp@latest
  • Step 2: Then paste the full prompt into Claude Code. It defines five personas: the impatient one, the skeptic, the mobile user on slow 3G, the non-native English speaker, and the breaker who pastes junk into every form.

Each subagent clicks from landing page to first success, screenshots every point of confusion, and merges findings into one ranked bug list. Claude fixes everything in one pass, then reruns all five to verify.
