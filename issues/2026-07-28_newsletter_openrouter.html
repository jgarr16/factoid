Generate images and video with the same API key

Media generation

The same key generates images and video, not just reads them

POST /api/v1/images and POST /api/v1/videos turn a text prompt into an image or a video, using the same API key and credit balance as every other request. Both are below.

Explore image and video models

Image generation

curl -X POST "https://openrouter.ai/api/v1/images" \ -H "Authorization: Bearer $OPENROUTER_API_KEY" \ -H "Content-Type: application/json" \ -d '{ "model": "bytedance-seed/seedream-4.5", "prompt": "a red panda astronaut floating in space, studio lighting" }'

The response returns the image directly. Swap the model slug for any of the 40 image-generation models in the catalog. Nano Banana and Seedream 4.5 are the two most-used right now; GPT Image 2, Nano Banana Pro, FLUX.2, and 35 more are in there too.

Video generation

Video generation is asynchronous: submit a job, then poll until it's done.

curl -X POST "https://openrouter.ai/api/v1/videos" \ -H "Authorization: Bearer $OPENROUTER_API_KEY" \ -H "Content-Type: application/json" \ -d '{ "model": "google/veo-3.1-lite", "prompt": "A cinematic 4-second shot of a glass greenhouse at sunrise, soft mist, slow dolly-in camera movement", "duration": 4, "resolution": "720p", "aspect_ratio": "16:9", "generate_audio": false }'

The response returns a job id immediately. Poll GET /api/v1/videos/{jobId} until status is completed, then download from the content URL. Swap the model slug for any of the 17 video-generation models in the catalog (Veo 3.1, Sora 2 Pro, Kling, Seedance, Wan, and more).

What carries over

No new setup. Image and video requests use the same key and draw from the same credit balance as every other call, at per-request pricing shown on each model's page.

The model picker is still the model field. Comparing models, or switching between image and video, is a one-string edit.

Two endpoints, one JSON body each.

POST /api/v1/images returns an image directly. POST /api/v1/videos returns a job you poll. Both take a model and a prompt; nothing else to set up.
