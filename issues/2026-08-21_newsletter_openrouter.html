GPT-5.6 Sol is half price on OpenRouter through September 18

Model pricing

GPT-5.6 Sol is half price on OpenRouter.

GPT-5.6 Sol is the flagship of OpenAI's GPT-5.6 series, built for coding, agents, and long-horizon reasoning, with a 1M-token context window. Through September 18, its OpenAI-hosted endpoints are 50% off on OpenRouter, batch and priority included: $2.50 input and $15 output per million tokens on standard (listed at $5 and $30). The discount applies automatically on openai/gpt-5.6-sol; there is no code to apply.

See GPT-5.6 Sol benchmarks

Where it scores

OpenRouter runs public benchmarks continuously against the same provider endpoints that serve production traffic, 2.4 million task evaluations to date. From the August 18 run:

GPQA Diamond 8th of 116

91.4% $0.10 / question · 63s

τ²-Bench Airline 14th of 115

77.3% $0.30 / task · 2.2m

Sol is not the top of either board, and the economics are worth reading: it reaches 91.4% on GPQA Diamond in 3.3k output tokens per question, while Sol Pro sits 2nd at 93.8% on 11.8k tokens and $0.44 a question. The top-scoring WideSearch run, 84.0%, also ran on Sol. Full leaderboards, run configurations, and per-provider results are on benchmarks.

In production

Sol is already carrying large agent workloads through OpenRouter. The model page lists its top public apps by token volume: Codex at 383B tokens, Hermes Agent at 206B, and Claude Code at 62.3B.

Pinning the discounted route

OpenRouter serves Sol from OpenAI, Azure, and Amazon Bedrock. The discount applies on the OpenAI provider for non-BYOK requests; Azure and Bedrock keep their listed prices, and default routing can select any eligible provider. To keep every request on the discounted route, set provider.only:

{ "model": "openai/gpt-5.6-sol", "provider": { "only": ["openai"] } }

With this set, requests do not fall back to Azure or Bedrock if OpenAI is unavailable. See provider selection.
