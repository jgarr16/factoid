FROM THE FRONTIER

Claude’s latest update has sparked an unexpected controversy

Made with Midjourney

What’s going on? Anthropic plans to start digitally watermarking all Claude-generated content, a decision it made to stay compliant with a new transparency requirement from the European Union. The goal is to make it easy to identify AI-generated content — but not everyone is on board.

The point of contention: This update will slap everything Claude touches with a digital “created by Claude” label.

  • If you tell Claude to write a blog post, that blog post gets a watermark.

  • If you write a blog post 100% by hand but have Claude spellcheck it, that entire post still gets a watermark.

Many feel this will lead to lots of human-created work getting attributed entirely to an LLM, especially because most employees are strongly encouraged to use AI. Others have questioned how this will impact enterprise use cases, where AI is one small part of a deeply collaborative process.

Where do we go from here? OpenAI and Google have also committed to the EU’s transparency rules, so expect similar policies from each, though both already use watermarks for images and audio. It’s hard to believe, but with how quickly AI content is scaling, labeling human work might soon be the easier solution.

TUTORIAL

How to build an AI agent engineering team (without hiring anyone)

Kevin Chan is one person. He is replacing 20+ SaaS tools for a 50-person business.

His method: an agent inbox per workflow instead of a subscription per workflow

  • Install the Nylas CLI and authenticate with your API key.

  • Give each workflow its own inbox: nylas agent account create renewals@team.nylas.email

  • Repeat for invoices@, offboarding@, support@.

  • Limit what each one can act on: nylas agent rule create --name "Carriers" --condition from.domain,is,spam.io --action block

  • Hand the set to your coding agent: nylas mcp install --assistant claude-code

Or do it all with one prompt: "Create Nylas agent accounts for renewals@ and invoices@, block senders outside our carrier domains, then list the roster."
