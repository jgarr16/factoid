INSIGHT

How to work when agents write 99% of your code

Source: The Code, Superhuman

Software development just forked. Nearly every engineering team has coding agents now. They write code, run tests, and fix failures for hours without a human. Yet, most teams aren't shipping any faster. The real split is between developers who just changed their coding tools and those who changed how they work. Only the second group is seeing massive productivity gains.

This insight comes from Clare Liguori, a senior principal engineer at AWS. She argues that top developers have stopped building software directly. Instead, they build the agentic systems that build the software. Once that setup is ready, they manually write less than 1% of the code they ship. Liguori calls this frontier engineering. She just dropped a guide to help other developers make the switch.

Your new job description. Her guide covers 10 core principles. Read together, they come down to three jobs, and those jobs are how you spend your day once you move beyond manual coding:

  • You're the architect now. You write intent, and the agent writes code. That means roles, edge cases, acceptance criteria, and how to test the failure path. Your review then checks the output against what you asked for.

  • Childproof the codebase. Fast local test loops, docs written for machines, tight permission boundaries, and a setup you keep tuning. The environment does the supervising so you don't have to hover.

  • Delegate everything and keep the bar. Give agents more of the work, including the tasks that aren't code. Throw away output that misses. Hold what's left to the same standard as a human's, because your name is still on the pull request.

The payoff compounds. Those first few weeks feel slower. But once you get through them, the re-architecture you kept putting off and the tests you never had time for finally click into place. You can find the full guide here.

AI CODING HACK

How to run Claude Code and Codex inside Grok Bot

You pay for Claude Code, Codex, and Cursor, but you can only drive one at a time, the rest of your quota sits idle. An AI builder shared a fix: install them all on Grok Bot's cloud machine and let it delegate.

  • Step 1: Open Grok Bot. It runs on a Linux cloud machine tied to your account.

  • Step 2: Send this prompt. Replace the bracketed values with your repo, task, and limits:

Install Codex CLI on your own cloud machine and guide me through signing in to use my existing subscription.

Clone [REPOSITORY URL] into a separate working directory and use Codex to complete [TASK]. The acceptance criteria are [EXPECTED RESULT]. Do not modify [OUT-OF-SCOPE AREAS].

Let Codex handle the implementation. Track its progress, give it the information it needs, and review its changes and test results. Don't redo the work yourself.

When it's done, send me the diff and test results, and tell me where to find the outputs. Ask me first if you need additional authorization.
  • Step 3: Grok Bot installs the agent, walks you through sign-in, then splits the work. It plans and reviews on its own quota while Codex writes code on yours.

Diffs and test results come back to your chat. Repeat the same setup for Claude Code or Cursor.
