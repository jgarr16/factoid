The fundamentals behind every LLM

Hi there,

LLMs are easier to build with when you understand how they work. Knowing how a model generates text, how it is trained, and what makes inference fast helps you choose the right model, debug unexpected behavior, and deploy it efficiently.

These five courses teach those fundamentals, from how transformers generate text to post-training and fast inference. Together, they build core skills in LLM foundations, one of the skills in our AI Engineering Skills Map.

1. Transformers in Practice

Reason about model behavior, debug problems, and make smarter decisions about deploying transformer-based models.

2. Fast & Efficient LLM Inference with vLLM

Optimize, deploy, and benchmark an open-source LLM with vLLM.

3. Fast LLM Inference with Cerebras

Learn what makes inference slow and build LLM applications that respond in real time.

4. Build and Train an LLM with JAX

Build and train an LLM from scratch, and learn the core techniques powering modern AI development.

5. Fine-Tuning & RL for LLMs: Intro to Post-training

Reason about, debug, and make deployment decisions for transformer models.
