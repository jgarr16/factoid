FROM THE FRONTIER

Anthropic studied millions of AI agent sessions — here's what they found

Made with Midjourney

Anthropic lifts the curtain. AI agents are having a major viral moment. But for all the hype, plenty of questions remain unanswered. Can agents actually automate tasks? Where are they being deployed? Anthropic’s newest study offers some much-needed insight.

Agents are working longer. Among the longest-running sessions, Claude shows the ability to work for 45 minutes at a time before stopping — nearly double what it was 3 months ago. This growth is also smooth across model releases, suggesting that the longer run times are driven by growing user trust, not better models.

Software engineering still dominates. Agents are still used primarily for writing and debugging code, with engineering tasks making up roughly 50% of calls on Anthropic’s API. Other verticals — like back-office automation, copywriting, and sales — are growing, but still represent a small portion of usage.

One big caveat. Anthropic admits 3 biases in its study: the data is limited to Claude users, only ranges from late 2025 through early 2026, and the insights were extracted by Claude, not humans (due to privacy concerns). Still, these types of studies are critical for industry transparency — and can challenge other AI labs to publish similar research.

How to create Chrome extensions using Claude Opus 4.6

  • Log in to Claude and select Opus 4.6

  • Generate the code for the extension. Use the prompt below.

Sample prompt: "Develop an extension that [how your extension should work, its features and how you can use it]. Generate the complete code, organize all the files into a folder, and create a downloadable folder named [Name of extension]"

  • Download the files created by Claude.

  • Extract the zip file and open Chrome's extensions manager.

  • Enable "Developer mode" in the top right corner.

  • Click "Load unpacked" and select your project folder.

  • Activate the extension.
